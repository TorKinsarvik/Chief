# CHIEF v2

Installerbar, offline-first PWA for avansert kroppsvekttrening.

## Publisering
Last opp hele mappen uendret til en statisk HTTPS-tjeneste, for eksempel Azure Static Web Apps, GitHub Pages, Netlify eller Vercel. Ikke åpne bare index.html som file:// dersom du vil teste installasjon og service worker.

## Lokal test
Kjør fra mappen: `python3 -m http.server 8080` og åpne `http://localhost:8080`. Localhost regnes som sikker kontekst i moderne nettlesere.

## Installasjon
- Chrome/Edge/Android: bruk INSTALLER CHIEF eller nettleserens installeringsikon.
- iPhone/iPad: Safari > Del > Legg til på Hjem-skjerm.

## Data
Historikk, rekorder og innstillinger lagres bare lokalt i nettleseren. Ingen konto eller skylagring.
